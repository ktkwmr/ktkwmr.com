# ktkwmr.com – domain root

The top page of https://ktkwmr.com/ (a list of all the apps, English and Japanese) and the other files at the domain root: `robots.txt`, `sitemap.xml`, the root icons, and the 404 page.
https://ktkwmr.com/ のトップページ（アプリ一覧、英語・日本語）と、ドメイン直下のファイル（`robots.txt`・`sitemap.xml`・ルートのアイコン・404 ページ）。

Each app is a separate repository and Worker with its own route `ktkwmr.com/<slug>*`. This Worker takes `ktkwmr.com/*`, i.e. every path no app takes (Cloudflare uses the most specific route), so no app depends on another.
アプリはそれぞれ別のリポジトリ・Worker で、ルート `ktkwmr.com/<slug>*` を持ちます。この Worker は `ktkwmr.com/*`（どのアプリのルートにも当たらないパス全部）を受け持ちます（Cloudflare は一番具体的なルートを使う）。これで、どのアプリもほかのアプリに依存しません。

## Structure / 構成

```
public/
  index.html  ja/index.html  sitemap.xml   # generated by scripts/build.mjs (do not edit)
  robots.txt         # Sitemap: lines for the top page and every app
  404.html           # unknown URLs at the domain root
  og-image.png  icon.svg  icons/           # generated by scripts/render-images.mjs (icon.svg is the source)
  _headers  _redirects
scripts/
  pages/home.mjs     # the top page; APPS lists the apps
  build.mjs          # writes the top page and sitemap.xml (--check to verify)
  og-image.html      # source of og-image.png
  render-images.mjs  # renders og-image.png and the icons (needs Playwright)
wrangler.jsonc
```

## Adding or updating an app / アプリの追加・更新

1. `scripts/pages/home.mjs`: add the icon to `ICON` (the paths inside the app's `icons/icon.svg`) and an entry to `APPS` (name, description, points, guides; English and Japanese).
2. `public/robots.txt`: add `Sitemap: https://ktkwmr.com/<slug>/sitemap.xml`.
3. `node scripts/build.mjs`, then a PR.

The same when an app adds, renames, or removes a guide, or changes its name, description, or icon.
アプリのガイド記事を追加・改名・削除したとき、アプリ名・説明・アイコンを変えたときも同じです。

## Development / 開発

```
npx wrangler dev   # http://localhost:8787/ (runs scripts/build.mjs first)
```

## Deploy / デプロイ

Cloudflare Workers Builds: a push to `main` deploys; PR branches get preview builds. The route `ktkwmr.com/*` is registered on deploy.
